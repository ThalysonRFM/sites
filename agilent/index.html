Documentação do Módulo agilent.py

Biblioteca Python para processamento, análise e visualização de dados de RMN Agilent/Varian pré-processados no ssNake.

Versão 1.0 Autor: Marcos de Oliveira Jr. Python 3.8+

Visão Geral

O módulo agilent.py foi desenvolvido para automatizar o fluxo de trabalho com espectros de Ressonância Magnética Nuclear (RMN) provenientes de espectrômetros Agilent/Varian e pré-processados no software ssNake. Ele encapsula rotinas das bibliotecas nmrglue e csdmpy, fornecendo uma interface orientada a objetos para manipular dados 1D e 2D.

Recursos Principais:

  • Leitura direta de dados de processamento (diretórios .fid contendo o arquivo de dados brutos e o arquivo .json exportado do ssNake).
  • Cálculo automático de escalas de deslocamento químico ($\delta$ / ppm) e Hz via objetos CSDM.
  • Integração de picos espectrais e análise automatizada de experimentos REDOR (Rotational Echo Double Resonance).
  • Visualização gráfica no estilo de publicações científicas usando Matplotlib.
  • Exportação flexível para ASCII, DMFit, CSDM e Pickle.

Instalação e Dependências

Certifique-se de que seu ambiente Python possui as seguintes dependências instaladas:

pip install numpy nmrglue matplotlib csdmpy ssnmr_proc

Estrutura de Arquivos Requerida:

O diretório de entrada precisa conter o arquivo .json do ssNake salvo com o mesmo nome da pasta Agilent:

meu_experimento.fid/
├── FID
├── procpar
└── meu_experimento.json  <-- Mesmo nome do diretório .fid

Início Rápido

Carregando, normalizando e plotando um espectro 1D em poucas linhas de código:

import matplotlib.pyplot as plt
from agilent import ssNakeProc

# Instancia e carrega o espectro do diretório .fid com o JSON do ssNake
spc = ssNakeProc(r"C:\Dados\Amostra01.fid")

# Normaliza pela intensidade do pico máximo
spc.normalize(method='intensity')

# Cria o ambiente gráfico
fig, ax = plt.subplots(figsize=(8, 4))

# Plota o espectro formatado para Carbono-13
spc.plot(axis=ax, nucleus='13C', major_ticks_space=50)

plt.show()

Classe ssNakeProc

Classe principal para carregar, processar e operar sobre um conjunto de dados Agilent/ssNake.

ssNakeProc(data_dir)

Inicializador. Carrega os arquivos processados e constrói a representação CSDM e as escalas de frequência e ppm.

Atributos Gerados:

Atributo Tipo Descrição
data ndarray (complex) Array com componentes real e imaginária do espectro.
fid ndarray (complex) Dados no domínio do tempo (Free Induction Decay).
ppm_scale ndarray Eixo de deslocamento químico ($\delta$ / ppm).
hz_scale ndarray Eixo de frequência em Hertz (Hz).
json dict Dicionário contendo todos os parâmetros originais do ssNake.
csdm_spec CSDM Objeto CSDM com metadados e dimensões configuradas.
dic dict Dicionário com parâmetros originais Agilent via nmrglue.
udic dict Dicionário universal de parâmetros do nmrglue.
area(region=tuple())

Calcula a área (integração trapezoidal) de uma região específica do espectro 1D.

Parâmetros: region (tuple): Intervalo de integração em ppm, ex: (150, 100). Se vazio, calcula a área total.

Retorno: float - Valor absoluto da área.

f2area(region=tuple())

Calcula a lista de áreas na dimensão F2 para dados 2D.

Retorno: ndarray - Array contendo as áreas integradas para cada incremento F2.

redor(region=tuple())

Processa experimentos REDOR 2D e extrai a curva de despolarização dipolar.

Retorno: Tupla (DS, NTR) contendo os valores de atenuação de sinal $\Delta S / S_0$ e os tempos de dephasing ($N_T R_r$) em segundos.

normalize(method='intensity', region=tuple())

Normaliza a intensidade dos dados espectrais.

Opções de Método:

  • 'intensity': Define o pico máximo do espectro real como 1.0.
  • 'area': Normaliza a área integrada da região informada para 1.0.
  • '01': Re-escala e ajusta os dados para o intervalo entre 0 e 1.
plot(axis, nucleus=None, major_ticks_space=None, minor_ticks_space=None, line_color='k', font_name='Times new roman')

Gera o gráfico 1D formatado no estilo de publicações em um objeto Axes do Matplotlib.

FFT() & iFFT()

Aplica a Transformada Direta de Fourier (FFT()) ou a Transformada Inversa de Fourier (iFFT()) nos dados espectrais.

Outros métodos de manipulação:

  • ls(pts=0): Aplica deslocamento esquerdo (Left Shift) de N pontos.
  • flip(): Inverte o array de dados no eixo horizontal.
save(filename='data.dat', file_type='ascii')

Exporta os dados em diferentes formatos. Opções de file_type:

  • 'ascii': Arquivo de texto em colunas [ppm, intensidade].
  • 'dmfit': Formato legível pelo software DMFit [Hz, intensidade].
  • 'csdf': Arquivo serializado da biblioteca CSDM.
  • 'pickle': Serializa a instância completa da classe Python.

Funções Auxiliares

load_pdata_obj(file_dir)

Recarrega uma instância da classe ssNakeProc salva anteriormente em formato Pickle.

from agilent import load_pdata_obj

# Restaura o objeto salvo
espectro = load_pdata_obj("meu_espectro.pickle")

Tutorial Prático do Módulo agilent.py

Guia passo a passo para carregar, tratar, integrar e exportar dados de RMN com Python.

Tutorial RMN Agilent/Varian ssNake

Visão Geral do Tutorial

Este tutorial orienta no uso prático do módulo agilent.py. Você aprenderá como automatizar a análise de espectros 1D e experimentos 2D (como REDOR), personalizar visualizações para artigos científicos e exportar os resultados tratados.

Pré-requisitos

Antes de iniciar, verifique se possui os pacotes necessários configurados no ambiente Python:

pip install numpy nmrglue matplotlib csdmpy ssnmr_proc

Certifique-se de que seus arquivos estejam salvos no seguinte formato:

amostra.fid/
├── FID
├── procpar
└── amostra.json  <-- Exportado via ssNake com o mesmo nome do diretório

1. Carregando Dados

A classe ssNakeProc lê automaticamente a pasta .fid e o arquivo de metadados .json gerado pelo ssNake.

from agilent import ssNakeProc

# Inicializa o objeto apontando para o diretório .fid
espectro = ssNakeProc(r"C:\Experimentos\MinhaAmostra.fid")

# Exibe informações do eixo ppm e dos dados
print(f"Pontos no espectro: {len(espectro.ppm_scale)}")
print(f"Intervalo em ppm: {espectro.ppm_scale.max():.2f} a {espectro.ppm_scale.min():.2f}")

2. Processando Espectros 1D

É possível aplicar manipulações no domínio da frequência ou do tempo, além de normalizar o sinal.

# Normaliza a intensidade do sinal máximo para 1.0
espectro.normalize(method='intensity')

# Exemplo de transformada inversa e aplicação de Left Shift
espectro.iFFT()
espectro.ls(pts=2)
espectro.FFT()

3. Integração de Áreas

Você pode calcular a área trapezoidal do espectro total ou restringir para uma região específica em ppm.

# Calcula a área da região entre 180 e 160 ppm (ex: carbonila)
area_carbonila = espectro.area(region=(180, 160))
print(f"Área Integrada: {area_carbonila:.4f}")

# Normaliza o espectro com base nessa área
espectro.normalize(method='area', region=(180, 160))

4. Análise de REDOR 2D

Para conjuntos de dados 2D de desacoplamento dipolar (REDOR), o método redor() extrai a curva de despolarização automaticamente.

# Carrega um experimento 2D REDOR
redor_exp = ssNakeProc(r"C:\Experimentos\REDOR_2D.fid")

# Define a região de interesse do pico e extrai DS (delta S / S0) e NTR (tempo)
DS, NTR = redor_exp.redor(region=(120, 100))

# Exibe os resultados calculados
for t, ds in zip(NTR, DS):
    print(f"Tempo: {t*1e3:.2f} ms | DS/S0: {ds:.4f}")

5. Exportação e Restauração

Salve os resultados para análise posterior em outros softwares ou restaure o objeto tratado diretamente no Python.

# Salva o espectro em formato de texto ASCII (ppm vs intensidade)
espectro.save(filename="espectro_processado.txt", file_type='ascii')

# Salva o estado completo do objeto Python usando Pickle
espectro.save(filename="sessao.pickle", file_type='pickle')

# Restauração posterior em outro script:
from agilent import load_pdata_obj
espectro_restaurado = load_pdata_obj("sessao.pickle")

Gráficos para Publicação

Gere figuras customizadas prontas para submissão usando o Matplotlib em conjunto com o método plot().

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(9, 4.5), dpi=300)

# Plota com formatação para Carbono-13 e marcas principais a cada 20 ppm
espectro.plot(
    axis=ax, 
    nucleus='13C', 
    major_ticks_space=20, 
    minor_ticks_space=5, 
    line_color='#0284c7'
)

ax.set_title("Espectro de RMN de 13C CP-MAS", fontsize=12, pad=12)
plt.tight_layout()
plt.show()
