Documentação Oficial: bruker.py

Referência da API para leitura, processamento e análise quantitativa de RMN Bruker TopSpin em Python.

Versão 1.0 Autor: Marcos de Oliveira Jr. Python 3.8+

Novo por aqui? Confira nossos Tutoriais Guiados!

Aprenda passo a passo como plotar espectros 1D/2D, integrar picos, extrair curvas REDOR e exportar dados.

Visão Geral

O módulo bruker.py foi desenvolvido para automatizar o fluxo de trabalho com espectros de Ressonância Magnética Nuclear (RMN) provenientes do software Bruker TopSpin. Ele encapsula rotinas da biblioteca nmrglue, fornecendo uma interface orientada a objetos para manipular dados 1D e 2D.

Recursos Principais:

  • Leitura direta de dados de processamento (pastas pdata/1 com arquivos 1r, 2rr).
  • Cálculo automático de escalas de deslocamento químico ($\delta$ / ppm) e Hz.
  • Integração de picos espectrais e análise de dados REDOR (Rotational Echo Double Resonance).
  • Visualização gráfica no estilo de publicações científicas usando Matplotlib.
  • Exportação para ASCII, DMFit, CSDM e Pickle.

Instalação

Instale as dependências necessárias através do pip:

pip install numpy nmrglue matplotlib csdmpy

Início Rápido

Carregando e plotando um espectro 1D em poucas linhas de código:

import matplotlib.pyplot as plt
from bruker import ProcData

# Instancia e carrega o espectro do diretório processado
spc = ProcData(r"C:\Dados\Amostra01\pdata\1")

# Cria ambiente de figura
fig, ax = plt.subplots(figsize=(8, 4))

# Plota o espectro para o núcleo de Carbono-13
spc.plot(axis=ax, nucleus='13C', major_ticks_space=50)

ax.set_xlim(220, -10)
plt.show()

Referência da API

ProcData(data_dir, verbose=True)

Classe Principal: Inicializa o objeto de dados de RMN apontando para o caminho do experimento do TopSpin (pasta pdata/1). Lê os binários e carrega os parâmetros de aquisição e processamento.

Atributos Gerados:

Atributo Tipo Descrição
dic dict Dicionário com parâmetros originais Bruker (acqus, procs).
data ndarray (complex) Array com componentes real e imaginária do espectro.
ppm_scale ndarray Eixo de deslocamento químico ($\delta$ / ppm) da dimensão f2.
ppm_scale_1 ndarray Eixo $\delta$ / ppm da dimensão f1 (apenas para dados 2D).
vdlist ndarray Lista de tempos de atraso (carregada se o arquivo vdlist existir).
area(region=None) / f2area(region=None)

Integração Quantitativa: Calcula a área numérica sob o sinal (integração trapezoidal) do espectro 1D ou projeção F2 no intervalo delimitado em ppm (ex: [180, 160]). Se omitido, calcula a área total.

redor(region=None, return_full_data=False)

Cálculo Dinâmico: Processa séries temporais de experimentos dipolar-recoupling. Calcula a curva de desfrutamento REDOR ($\Delta S / S_0$) integrando picos específicos para cada tempo de evolução.

normalize(method='intensity', region=None)

Tratamento de Dados: Normaliza a escala de intensidade dos espectros. As opções incluem 'intensity' (pico máximo em 1.0), 'area' (área integrada em 1.0), '01' (escala entre 0 e 1) e 'scans' (divisão por NS).

plot(axis, nucleus=None, major_ticks_space=None, line_color='k') / plot2D(...)

Visualização Gráfica: Plota espectros 1D ajustando os eixos em ppm/Hz ou gera mapas de contorno 2D com níveis e paletas personalizáveis, com suporte a projeções skyline acopladas nas bordas.

save(filename, file_type='ascii')

Exportação: Converte e salva os vetores de intensidade e eixos de deslocamento químico para formatos como ASCII (.dat), DMFit (.txt), CSDM (.csdf) e Pickle (.pkl).

Funções Auxiliares

load_pdata_obj(file_dir)

Recarrega um objeto ProcData salvo anteriormente em formato Pickle.

from bruker import load_pdata_obj

# Restaura o objeto salvo
espectro = load_pdata_obj("meu_espectro.pkl")

Tutoriais Práticos

Guias passo a passo para processamento, análise quantitativa e visualização gráfica com o bruker.py.

Guias Práticos Exemplos de Código Casos Reais

1. Plotagem 1D Básica e Customização

Aprenda a carregar um experimento 1D e personalizar eixos, cores e marcações de escala de deslocamento químico.

import matplotlib.pyplot as plt
from bruker import ProcData

# Carrega dados do TopSpin
spc = ProcData(r"C:\RMN\Amostra_Polimero\10\pdata\1")

fig, ax = plt.subplots(figsize=(9, 4.5))

# Plota com parâmetros customizados
spc.plot(
    axis=ax, 
    nucleus='13C', 
    major_ticks_space=20, 
    line_color='#0284c7'
)

ax.set_xlim(200, 0)
ax.set_title("Espectro 13C CP/MAS", fontsize=12, fontweight='bold')
plt.tight_layout()
plt.show()

2. Integração e Normalização de Picos

Como calcular a área sob picos específicos e comparar diferentes amostras normalizando por área ou por número de varreduras (NS).

from bruker import ProcData

spc = ProcData(r"C:\RMN\Amostra_Carbonato\1\pdata\1")

# 1. Integração da região de carbonila (170 a 160 ppm)
area_carb = spc.area(region=(170, 160))
print(f"Área da Carbonila: {area_carb:.4f}")

# 2. Normaliza todo o espectro em relação a essa área
spc.normalize(method='area', region=(170, 160))

# Agora a área da região (170, 160) é exatamente 1.0
print(f"Área Normalizada: {spc.area(region=(170, 160)):.4f}")

3. Análise de Curva REDOR

Extração automática de curvas de desfrutamento dipolar ($\Delta S / S_0$) a partir de uma série pseudo-2D de experimentos REDOR.

import matplotlib.pyplot as plt
from bruker import ProcData

# Carrega a série REDOR 2D
redor_exp = ProcData(r"C:\RMN\REDOR_13C_15N\pdata\1")

# Calcula desfrutamento na região do grupo funcional
DS, NTR = redor_exp.redor(region=(175, 165))

# Plota a curva de desfrutamento REDOR
plt.figure(figsize=(6, 4))
plt.plot(NTR, DS, 'o-', color='#ea580c', label='Região Carbonila')
plt.xlabel("Tempo de Recoupling (ms)")
plt.ylabel("ΔS / S0")
plt.grid(True, linestyle='--', alpha=0.6)
plt.legend()
plt.show()

4. Espectros 2D e Mapas de Contorno

Gere visualizações de experimentos bidimensionais (HETCOR, SQ-DQ, COSY) ajustando níveis de contorno e paletas de cores.

import matplotlib.pyplot as plt
from bruker import ProcData

exp2d = ProcData(r"C:\RMN\HETCOR_1H_13C\1\pdata\1")

fig, ax = plt.subplots(figsize=(7, 6))

# Plota mapa de contornos 2D
exp2d.plot2D(
    axis=ax, 
    cmap='viridis', 
    clevels=15, 
    clevel_factor=1.3
)

ax.set_xlabel("13C (ppm)")
ax.set_ylabel("1H (ppm)")
plt.show()

5. Exportando Dados para Análise Externa

Como exportar o espectro processado para formatos compatíveis com outros softwares de ajuste (ex: DMFit) ou ASCII simples.

from bruker import ProcData

spc = ProcData(r"C:\RMN\Amostra_Silica\1\pdata\1")

# Exporta duas colunas [ppm, intensidade] para Origin/Excel
spc.save("meu_espectro.dat", file_type='ascii')

# Exporta no formato específico para fitting no DMFit
spc.save("para_dmfit.txt", file_type='dmfit')
